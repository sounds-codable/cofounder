# 🤝 叩饭（Cofounder）

**行业专家 × 程序员 = 合伙创业**

> 不是雇佣，是合伙；不谈工资，谈股权；先做MVP，再定分配。

叩饭（Cofounder）是一个连接项目方（行业专家）与程序员的协作平台。平台强调低门槛发布、渐进式补充资料，以及基于双向授权的信息解锁与联系方式交换。

## 📌 当前状态

- **当前阶段**：仅完成产品文档与重构方案整理，暂未开始实际迁移开发
- **前端目标**：从 `Taro` 重构为 `Next.js v16`
- **后端目标**：继续使用 `NestJS`，业务能力与接口将围绕新流程迭代
- **当前有效产品文档**：`docs/产品需求文档-角色双向授权与Nextjs重构.md`

## 🎯 产品核心规则

- **[双角色]** 平台包含两种角色：项目方（行业专家）与程序员
- **[基础信息公开]** 未登录用户只能浏览双方的基础信息
- **[登录后互动]** 收藏、点赞、了解详情都要求先登录
- **[渐进式录入]** 用户先填写最少基础信息，只有在需要更深入沟通时才填写详细信息
- **[详细信息只填一次]** 详细信息一旦完成，后续所有请求复用
- **[双阶段解锁]** 先开放详细信息，再通过单独动作交换联系方式
- **[禁止自看]** 发布者不能对自己发布的信息发起“了解详情”

## 🧭 关键业务流程

### 1. 浏览阶段

- 未登录用户可查看：
  - 项目方基础信息：项目描述、所在城市
  - 程序员基础信息：技能与项目经历简介、想做的方向（选填）、所在城市
- 未登录用户不可进行收藏、点赞、了解详情

### 2. 了解详情阶段

- 用户登录后可收藏、点赞
- 用户点击 `了解详情` 时：
  - 如果自己未填写详细信息，先引导补全
  - 如果已填写，则可发送请求给发布者
- 发布者收到请求后：
  - 可直接看到请求者基础信息
  - 可看到请求者详细信息的打码版本
  - 若要看未打码详细信息，必须先确保自己也已填写详细信息

### 3. 发布者处理阶段

- 发布者在 `查看对方详细信息` 之后，才能点击：
  - `同意`
  - `拒绝`
- 若拒绝：必须填写拒绝理由
- 若同意：
  - 意向者可以看到发布者详细信息
  - 但仍看不到发布者联系方式

### 4. 交换联系信息阶段

- 意向者在获得同意后，可点击 `交换联系信息`
- 该动作要求意向者选择并发送自己的联系方式
- 完成后：
  - 意向者看到发布者授权的联系方式
  - 发布者看到意向者本次发送的联系方式

## 🚀 当前可用的本地开发信息

虽然前端迁移尚未开始，但后端 NestJS 服务仍可单独运行，用于后续接口梳理与联调准备。

### 环境要求

- Node.js >= 18
- PostgreSQL >= 15

### 后端启动

1. 复制环境变量文件

```bash
cp server/.env.example server/.env
```

2. 按需修改 `server/.env`

说明：

- 后端配置以 `server/.env` 为准
- 根目录 `.env` 不影响 NestJS 服务读取的数据库配置
- 默认开发端口为 `3010`

3. 安装并启动后端

```bash
npm install --prefix server
npm run start:dev --prefix server
```

启动后默认访问：`http://localhost:3010`

### 开发环境登录说明

开发环境下，邮箱验证码会打印在后端控制台中，便于本地调试登录流程。

## ⚙️ 关键环境变量

复制 `server/.env.example` 为 `server/.env` 后，重点关注：

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `NODE_ENV` | 运行环境 | `development` |
| `PORT` | 后端端口 | `3010` |
| `DB_HOST` | 数据库地址 | `localhost` |
| `DB_PORT` | 数据库端口 | `5432` |
| `DB_DATABASE` | 数据库名 | `hehuozao` |
| `JWT_SECRET` | JWT 密钥 | 需自行配置 |
| `MAIL_HOST` | SMTP 服务器 | 按实际配置 |
| `MAIL_USER` | 邮箱账号 | 按实际配置 |
| `MAIL_PASS` | SMTP 授权码 | 按实际配置 |
| `WAITLIST_DOUBLE_OPTIN_ENABLED` | Waitlist 二次验证开关 | `true` |
