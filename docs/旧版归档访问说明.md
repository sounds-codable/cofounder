# 旧版归档访问说明

旧版 Taro 前端与旧版 NestJS 后端已经移动到：

- `archive/client`
- `archive/server`

这样做是为了让新的 `client/` 与 `server/` 可以继续复用现有部署脚本和目录约定。

## 1. 访问旧版前提

建议分别准备两个终端窗口：

- 一个运行旧版后端
- 一个运行旧版前端

旧版前后端仍按原来的本地联调方式运行：

- 旧版后端端口：`3010`
- 旧版前端 H5 端口：`10086`

## 2. 启动旧版后端

### 2.1 准备环境变量

如果你还没有旧版环境变量文件，可先复制：

```bash
cp archive/server/.env.example archive/server/.env
```

然后按需修改 `archive/server/.env`。

### 2.2 启动命令

```bash
npm install --prefix archive/server
npm run start:dev --prefix archive/server
```

### 2.3 访问地址

- 健康检查或接口前缀：`http://localhost:3010`
- 如果旧版接口使用 `/api` 前缀，则访问形式为：`http://localhost:3010/api/...`

## 3. 启动旧版前端（Taro H5）

```bash
npm install --prefix archive/client
npm run dev:h5 --prefix archive/client
```

启动后旧版 H5 页面默认访问：

- `http://localhost:10086/`

## 4. 旧版本地联调关系

旧版前端开发代理仍指向：

- `http://localhost:3010`

因此本地访问旧版页面时，通常只需要：

1. 先启动旧版后端
2. 再启动旧版前端
3. 浏览器打开 `http://localhost:10086/`

## 5. 归档目录的意义

归档后的旧代码仍可继续：

- 对照旧实现逻辑
- 临时回看旧页面
- 迁移字段与接口时作参考

但后续正式开发、部署与文档，都以新的根目录：

- `client/`（Next.js v16）
- `server/`（NestJS v11）

为准。
